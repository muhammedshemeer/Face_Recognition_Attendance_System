# Face Recognition Attendance System 👤

An elegant, real-time face recognition-based attendance management system built with Streamlit, OpenCV, Face Recognition (dlib), and Firebase.

## Deployment on Hugging Face Spaces

This repository is optimized for deployment on Hugging Face Spaces using the **Streamlit SDK**.

### Configuration Files Included:
- **`README.md`**: Contains the Hugging Face Space metadata (YAML header).
- **`requirements.txt`**: Python dependencies including `opencv-python-headless` and `face-recognition`.
- **`packages.txt`**: Debian system dependencies (`cmake`) to compile `dlib` during build.
